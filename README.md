Experiment 10 – Express REST API CRUD

📌 Description

This project demonstrates how to build a REST API using Node.js and Express.js to perform CRUD operations on data.

✨ Features

- Create new records
- Read and retrieve records
- Update existing records
- Delete records
- Handle HTTP requests and API responses

🛠️ Technologies Used

- Node.js
- Express.js
- JavaScript
- REST API

🚀 How to Run

1. Install Node.js.
2. Open the project folder in a terminal.
3. Install dependencies:
   npm install
4. Start the server:
   node app.js
5. Test the API using a browser or Postman.

🎯 Objective

To understand REST API development using Express.js and learn how to perform Create, Read, Update, and Delete (CRUD) operations.

✅ Expected Outcome

A working REST API that handles CRUD operations through HTTP requests.
